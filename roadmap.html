Learning Roadmap

From Wet Lab to
Computational Biology

A practical, stage-by-stage roadmap for experimental biologists who want to add computational skills.

By Kian Gaikani, PhD · Built from a postdoc's perspective

If you're a wet-lab biologist who wants to get more out of sequencing data, run your own analyses, or eventually move into a hybrid role, this roadmap is for you. It's not about becoming a computer scientist. It's about becoming a biologist who can think computationally and collaborate effectively with people who do.

The sequence matters. Each stage builds on the previous one, and the most common mistake is jumping ahead or switching resources mid-way. Pick one resource per stage, finish it, and move on.

0
Foundation · Run in parallel with Stage 1

Math Literacy — Linear Algebra

Most ML and bioinformatics tools involve linear algebra under the hood — matrix operations, dimensionality reduction (like PCA), clustering. You don't need to master it, but a visual intuition makes everything easier later. Watch a few videos alongside Stage 1 rather than treating this as a prerequisite.

3Blue1Brown — Essence of Linear Algebra ↗
Free YouTube playlist. Visual, intuitive, no prerequisites. ~3 hours total.
1
Months 1–3

Python Fluency

Python is the foundation for everything else on this roadmap — data manipulation, bioinformatics tools, and ML all run on it. The goal here is functional literacy, not mastery: loops, functions, file handling, basic data structures. Skip algorithms and software engineering theory for now.

CS50P (Harvard's Python course) is the best starting point. It's taught clearly, it's free, and it's specifically designed for Python — not a general programming course that happens to use Python.

CS50P — Harvard Introduction to Python (YouTube) ↗
Free. Python-specific. Recommended first choice.
CS50P — edX (auditable for free) ↗
Same course, structured platform with problem sets.
2
Months 3–5

Data Python for Biology

Now that Python basics are in place, learn the scientific stack: pandas for data frames, numpy for numerical operations, and matplotlib/seaborn for visualization. These are the tools you'll use daily in bioinformatics work.

The most important habit to develop here: apply everything to your own data immediately. Take a result you've previously plotted in GraphPad Prism or R, and reproduce it in Python. This "anchor learning" is the fastest way to make new skills stick.

Kaggle Learn — Free Micro-Courses ↗
Browser-based, no setup required. Take the Python, Pandas, and Data Visualization modules. Each takes a few hours.
3
Month 5+ · Ongoing alongside postdoc work

Bioinformatics Python

This is where biology and computation start to feel like the same thing. Two parallel tracks: building algorithmic intuition for sequence data, and getting hands-on with a real analysis tool.

For the algorithms side, Compeau & Pevzner's textbook builds genuine understanding — not just tool usage. For the practical side, scanpy (single-cell analysis in Python) and DIYtranscriptomics (RNA-seq from the ground up) are both excellent entry points depending on your research context. Don't try to learn both at once — pick the one most relevant to your postdoc data.

Bioinformatics Algorithms — Compeau & Pevzner ↗
Free interactive version online. 11 chapters. Builds deep intuition for sequence analysis, not just tool usage.
Companion Video Lectures (YouTube) ↗
Paired walkthroughs for each chapter of the textbook above.
DIYtranscriptomics ↗
RNA-seq analysis from raw data to biological insight. Taught by Daniel Beiting (Penn). Excellent for anyone with transcriptomics data — R-based but very accessible.
scanpy — apply to a public single-cell dataset from GEO
No separate course needed here — just load a relevant dataset and start exploring. The documentation is excellent.
4
Month 6+

ML for Biology

By this point, you have enough Python and biological context to start engaging with machine learning in a meaningful way. The goal isn't to build ML models from scratch — it's to understand what these tools are doing well enough to use them critically in your research.

fast.ai's course is unusual in that it teaches applications first and theory second. That's exactly the right order for a working scientist. After completing it, you'll be able to read papers that use pre-trained biological models like ESM (protein sequences) or scGPT (single-cell data) and understand the methods well enough to evaluate them.

fast.ai — Practical Deep Learning for Coders ↗
Free. Application-first. Designed for practitioners, not engineers. One of the best-structured technical courses available.
The most important principle

The "lost" feeling almost always comes from switching resources, not from the difficulty of the material itself. Pick one resource per stage, complete it, then move on. Progress compounds when it's linear.
